# Localization (i18n)

`@iyulab/modern-app` uses [i18next](https://www.i18next.com/) for internationalization. Pass an `i18n` option to `app.load()` to enable it. The field accepts the standard `i18next.InitOptions` plus an optional `plugins` array.

---

## Basic setup

```typescript
import i18nextHttpBackend from 'i18next-http-backend';

await app.load({
  // ...
  i18n: {
    plugins: [i18nextHttpBackend],
    lng: 'en',
    fallbackLng: 'en',
    ns: ['common', 'admin'],
    defaultNS: 'common',
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json',
    },
  },
});
```

Plugins are passed to `i18next.use()` before `i18next.init()` is called under the hood.

---

## `I18nInitOptions`

```typescript
type I18nInitOptions = i18next.InitOptions & {
  /** i18next plugins to register via i18next.use() before init. */
  plugins?: (Module | NewableModule<Module> | Newable<Module>)[];
};
```

If `i18n` is omitted entirely, i18next is left uninitialized and `app.i18n` will point to the bare i18next instance.

---

## Accessing i18next at runtime

```typescript
// Raw i18next instance
app.i18n.t('common::greeting');
app.i18n.changeLanguage('ko');
app.i18n.language;   // current language
```

## Using translations in Lit templates

`translate()` is a Lit directive bound to the i18next instance `app.load()` initializes. No extra
package is needed:

```typescript
import { translate } from '@iyulab/modern-app';

render() {
  return html`
    <h1>${translate('common::title')}</h1>
    <p>${translate('admin::welcome', { name: this.user.name })}</p>
  `;
}
```

The directive is reactive. The part it renders updates when:

- the language changes (`app.i18n.changeLanguage()`),
- resources arrive later (a backend loading a namespace after the first render),
- i18next finishes initializing — until then the directive renders an empty string rather than the
  key, because shell configuration is created before `app.load()` initializes i18next.

A template that is disconnected stops listening, and catches up on the current language when it is
reconnected. Values that are not strings (`returnObjects`) render as an empty string.

It also works as a sidebar item `label`, which accepts a directive result:

```typescript
app.load({
  layout: {
    type: 'sidebar',
    main: [{ type: 'link', label: translate('nav::home'), href: '/' }],
  },
});
```

In a collapsed sidebar the label is hidden visually but stays in the accessibility tree, so a
translated label still names the item.

> Migrating from `lit-i18n`: replace `import { translate } from 'lit-i18n'` with
> `import { translate } from '@iyulab/modern-app'`, and drop `initLitI18n` from `i18n.plugins`.

## Translation file example

`/locales/en/common.json`:

```json
{
  "title": "My Application",
  "greeting": "Hello, {{name}}!",
  "nav": {
    "home": "Home",
    "users": "Users"
  }
}
```

Usage with namespaced key: `translate('common::nav.home')`
